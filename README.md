# Bank Account Management System 🚀

This is a Java-based **Bank Account Management System** that implements OOP concepts such as **Encapsulation, Inheritance, and Polymorphism**.

## 📌 Features
- Create and manage bank accounts
- Deposit and withdraw money
- Calculate interest for savings accounts
- Handle exceptions for invalid transactions

## 🛠️ Technologies Used
- **Java** for Backend
- **Git & GitHub** for Version Control

## ⚙️ Setup & Run
```sh
git clone https://github.com/anirudh2843/Bank_Acc_Management_System.git
cd Bank_Acc_Management_System
javac BankAccountApplication.java
java BankAccountApplication
